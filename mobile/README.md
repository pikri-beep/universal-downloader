# Universal Media Downloader — Mobile (Android Native)

Bagian ini diperuntukkan untuk **Fase 2**:
- Stack: **Kotlin + Jetpack Compose**
- Engine: `youtubedl-android` (library pembungkus `yt-dlp` dan `ffmpeg` native untuk Android)
- Target: File APK mandiri yang bisa diinstall langsung di smartphone Android tanpa koneksi ke laptop.
